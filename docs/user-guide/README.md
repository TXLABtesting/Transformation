# دليل المستخدم — مشروع الذكاء الاصطناعي المساعد

دليل بصري من خمس صفحات يُوزَّع على المستخدمين النهائيين في الجهات الاتحادية:
غلاف يعرّف بالمنصّة، ثم أربع صفحات لأهم شاشاتها — قوائم الحصر، إضافة المدخلات،
تفاصيل المدخل، دفعات الإطلاق. كل صفحة عنوان وسطر أو سطران ولقطة كبيرة من
النسخة الحالية للمنصّة.

## الملفات

| الملف | ما هو |
| --- | --- |
| `دليل-المستخدم.pdf` | الدليل الجاهز للتوزيع — A4 أفقي، خمس صفحات |
| `screens/` | اللقطات المستخدمة في الدليل بدقة الطباعة |
| `capture_screens.js` | يلتقط اللقطات الأربع من النسخة التجريبية |
| `sample_data.js` | بيانات عرض لوزارة المالية تُملأ بها الجداول في اللقطات |
| `build_pdf.py` | يبني `print.html` من اللقطات وصفحات الدليل |

## قواعد اللقطات

- **لا يظهر شريط الترويسة العلوي** (`[data-r="hdr"]`) لأنه يحمل دور المنسق واسم
  الجهة، والدليل يُرسَل للجميع — يُخفيه `capture_screens.js` قبل كل لقطة.
- **لا يظهر جدول «بلا فترة تحويل – للتحديد»** في صفحة دفعات الإطلاق.
- اللقطات من واجهة منسق المسار في جهة اتحادية، وهي رحلة المستخدم النهائي.

## إعادة التوليد

```bash
# 1) نسخة تجريبية تعمل على المنفذ 3299
NEXT_PUBLIC_DEMO_MODE=1 NEXT_PUBLIC_DEMO_DATA=1 NEXT_PUBLIC_BASE_PATH=/Transformation npm run export

# 2) التقاط اللقطات (يحتاج Playwright + Chromium)
node docs/user-guide/capture_screens.js

# 3) بناء صفحة الطباعة ثم تصديرها PDF من المتصفح بمقاس A4 أفقي بلا هوامش
python3 docs/user-guide/build_pdf.py
```
